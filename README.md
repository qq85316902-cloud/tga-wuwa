# 索拉里斯状态栏扩展

在原作者状态栏基础上，为“索拉里斯／鸣潮”增加旅行地图、潮汐主线、独立伴星任务和章节结束条件。其他世界观运行下载到的原版源码。

## 资料自动更新（不用反复导卡）

保留当前角色卡和外置状态栏，只需在酒馆助手当前角色脚本库导入并启用一次 [鸣潮资料自动更新](dist/solaris-sync.json)。以后刷新酒馆自动检查仓库更新；不重置聊天、人物数值或剧情进度。覆盖鸣潮世界书及地图前端字符串，开场和其他脚本不自动替换。

[安装、更新范围与恢复说明](AUTO-UPDATE.md)。34组离线场景通过；尚未在用户实际酒馆实测。

## 安装

酒馆助手中编辑角色脚本“外置状态栏”，只保留：

```js
import 'https://cdn.jsdelivr.net/gh/qq85316902-cloud/tga-wuwa@main/dist/status-bar.js';
```

也可下载 `dist/status-bar.json`，导入酒馆助手并启用。关闭旧的同类状态栏脚本，避免重复启动。仍需原卡的酒馆助手、MVU、变量结构和配套世界书。

从之前内置状态栏修复版升级时，还须替换三条配套正则：`dist/cover-regex.json`（封面）、`dist/bottom-regex.json`（状态栏）、`dist/bottom-fallback-regex.json`（状态栏缺失时补显示）。它们去掉旧版启动完整状态栏的后备代码。使用配套“统一外链版”角色卡时已完成这些替换。

## 运行与更新

- `dist/status-bar.js` 是唯一入口，读取当前 `系统配置.世界观`，同时监听变量更新并每秒复查。
- 原作者地址保存在入口顶部 `UPSTREAM_URL`，每次重新加载入口获取一次；本仓库不复制发布原作者完整状态栏。
- 索拉里斯改动存放在 `dist/solaris-patch.json`。按唯一源码上下文匹配，所有补丁成功后才运行结果，不会运行半套补丁。
- 切换世界观会清理面板、事件监听及运行环境，不写入人物、剧情或世界观变量。
- 原作者兼容更新会保留；结构变化导致补丁不匹配，或补丁版初始化失败时，提示并运行原版。此时索拉里斯扩展暂不可用，需更新补丁；刷新后重试。
- 原版下载失败会提示，并在30秒后重试。未提供离线原版副本。
- 原作者若迁移发布路径，需要同步修改 `UPSTREAM_URL`。`@latest` 只跟随当前仓库标签解析，无法自动知道新的文件路径；CDN更新也可能有延迟。

切换运行环境会关闭当前展开的状态栏窗口。角色进度仍由原有MVU保存，不由入口清零。索拉里斯扩展是否适配未来原版，以兼容检查和实际功能验证为准。

## 检查

浏览器控制台可查看 `window.__solarisStatusController`（酒馆主页面）：`mode` 为 `original`、`solaris`、`original-fallback` 或 `error`，`error` 记录失败原因。封面只有在状态栏实际初始化并暴露面板接口后才显示就绪。
